::question{id="itr-1" lesson="l6-from-an-idea-to-a-rulebook"}
A complete rulebook covers:
- [x] Market, setup, entry, stop, exit and position size
- [ ] Only the entry signal
- [ ] Only the profit target
? Every part of the trade needs a rule, or the strategy can't be tested or repeated.
::
::question{id="itr-2" lesson="l6-from-an-idea-to-a-rulebook"}
Which part of the rulebook must every single trade have?
- [x] An initial stop-loss
- [ ] A partial close
- [ ] A trailing stop
? Without a stop, the risk on a trade is undefined.
::
::question{id="itr-3" lesson="l6-from-an-idea-to-a-rulebook"}
"Buy pullbacks in an uptrend" is:
- [x] An idea that still needs precise rules before it can be tested
- [ ] A complete strategy
- [ ] A rule anyone could follow identically
? "Pullback" and "uptrend" both need exact definitions.
::
::question{id="itr-4" lesson="l6-from-an-idea-to-a-rulebook"}
Why write the rules down before testing?
- [x] So the test measures the rules, not your judgement in hindsight
- [ ] Because writing makes trades win
- [ ] So you can change them after seeing the results
? Fixed rules make the test honest and repeatable.
::
::question{id="itr-5" lesson="l6-writing-rules-anyone-could-follow"}
Which rule could two different people follow and get the same result?
- [x] "Enter when the 1-hour candle closes above the previous candle's high"
- [ ] "Enter when momentum looks strong"
- [ ] "Enter when the setup feels right"
? Precise, measurable conditions remove interpretation.
::
::question{id="itr-6" lesson="l6-writing-rules-anyone-could-follow"}
A good test of whether a rule is clear enough is:
- [x] Could a stranger, or a computer, apply it and mark the same trades as you?
- [ ] Does it sound professional?
- [ ] Is it long?
? If others would mark different trades, the rule is too vague.
::
::question{id="itr-7" lesson="l6-writing-rules-anyone-could-follow"}
Which word in a rule is a warning sign that it's too vague?
- [x] "Strong"
- [ ] "Closes"
- [ ] "50-period"
? Words like strong, clear or nice need numbers behind them.
::
::question{id="itr-8" lesson="l6-writing-rules-anyone-could-follow"}
How would you make "the stop goes below support" precise?
- [x] "The stop goes 5 pips below the most recent swing low, defined as a low with 3 higher lows on each side"
- [ ] "The stop goes somewhere safe"
- [ ] "The stop goes where it feels right on the day"
? Precise definitions turn a vague idea into a testable rule.
::
