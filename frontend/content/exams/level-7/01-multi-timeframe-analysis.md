::question{id="mtf-1" lesson="l7-the-triple-screen-idea"}
In Alexander Elder's triple screen idea, the longest timeframe is used to:
- [x] Set the direction you'll trade in
- [ ] Time the exact entry
- [ ] Place the profit target only
? The long timeframe decides whether you look only for buys or only for sells.
::
::question{id="mtf-2" lesson="l7-the-triple-screen-idea"}
In the triple screen, the middle timeframe:
- [x] Finds the setup, such as a pullback against the main direction
- [ ] Sets the long-term direction
- [ ] Is ignored
? The middle screen looks for a pullback within the bigger trend.
::
::question{id="mtf-3" lesson="l7-the-triple-screen-idea"}
The shortest timeframe in the triple screen is used to:
- [x] Time the entry once the pullback shows signs of ending
- [ ] Decide the trend
- [ ] Choose which pair to trade
? The short screen fine-tunes the entry.
::
::question{id="mtf-4" lesson="l7-the-triple-screen-idea"}
Why are the three timeframes usually about five times apart?
- [x] So each screen shows a genuinely different view, not the same picture twice
- [ ] Because brokers only offer those timeframes
- [ ] To create more trades
? Spacing timeframes apart gives each one a distinct job.
::
::question{id="mtf-5" lesson="l7-testable-multi-timeframe-rules"}
Which multi-timeframe rule is testable?
- [x] "Daily close above the 50-day SMA; on the 4-hour, price touches the 20-period MA; enter on a 1-hour close above the prior high"
- [ ] "Trade with the big trend and enter when it looks ready"
- [ ] "Check a few charts until one agrees"
? Each timeframe has a precise, measurable condition.
::
::question{id="mtf-6" lesson="l7-testable-multi-timeframe-rules"}
When backtesting multi-timeframe rules, what must you avoid?
- [x] Using a higher-timeframe candle that hadn't closed yet at the time of entry
- [ ] Using more than one timeframe
- [ ] Testing more than one pair
? Peeking at an unfinished daily candle is look-ahead bias and inflates results.
::
::question{id="mtf-7" lesson="l7-testable-multi-timeframe-rules"}
Adding a higher-timeframe trend filter to a strategy usually:
- [x] Cuts the number of trades, so you need a longer test to get enough of them
- [ ] Increases the number of trades
- [ ] Guarantees a better result
? Filters remove trades. Check that the sample stays large enough.
::
::question{id="mtf-8" lesson="l7-testable-multi-timeframe-rules"}
How do you know whether the higher-timeframe filter actually helps?
- [x] Test the strategy with and without it, on the same data and costs
- [ ] Assume it helps, because it sounds sensible
- [ ] Look at a few charts where it worked
? Only a direct comparison shows the filter's effect.
::
