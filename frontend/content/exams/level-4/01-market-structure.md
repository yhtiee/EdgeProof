::question{id="ms-1" lesson="l4-reading-a-price-chart"}
On a standard price chart, the horizontal axis shows:
- [x] Time
- [ ] Price
- [ ] Trading volume
? Time runs left to right; price runs up the vertical axis.
::
::question{id="ms-2" lesson="l4-reading-a-price-chart"}
On a 1-hour chart, each candle or bar represents:
- [ ] One trade
- [x] One hour of price movement
- [ ] One day of price movement
? The timeframe sets how much time each candle covers.
::
::question{id="ms-3" lesson="l4-swing-highs-and-swing-lows"}
A swing high is:
- [x] A peak: a high with lower highs on both sides
- [ ] Any candle that closes up
- [ ] The highest price of the year
? Swing points are the turning points that make up market structure.
::
::question{id="ms-4" lesson="l4-swing-highs-and-swing-lows"}
A market making higher highs and higher lows is:
- [x] In an uptrend
- [ ] In a downtrend
- [ ] In a range
? Rising peaks and rising valleys describe an uptrend.
::
::question{id="ms-5" lesson="l4-swing-highs-and-swing-lows"}
Why turn "swing low" into a precise rule, such as "a low with at least 3 higher lows on each side"?
- [x] So that anyone, or a computer, would mark the same points and the idea can be tested
- [ ] Because brokers require it
- [ ] To make the chart look cleaner
? Vague definitions can't be tested. Precise ones can.
::
::question{id="ms-6" lesson="l4-when-structure-breaks"}
In an uptrend, price closes below the last swing low. That suggests:
- [x] The "higher lows" pattern has broken, at least for now
- [ ] The uptrend is guaranteed to continue
- [ ] Nothing; swing lows don't matter
? A break of structure means the simple uptrend description is no longer true for now.
::
::question{id="ms-7" lesson="l4-when-structure-breaks"}
A candle's wick dips below the last swing low, but the candle closes above it. Under a rule that says "a break needs a close below", has structure broken?
- [ ] Yes
- [x] No
- [ ] Only on Fridays
? The rule is about the close, not the wick.
::
::question{id="ms-8" lesson="l4-when-structure-breaks"}
After price breaks below an uptrend's swing low, which outcomes are possible?
- [x] A reversal into a downtrend, or a false break that quickly recovers
- [ ] Only a reversal
- [ ] Only a continuation higher
? A break shifts the odds but doesn't tell you which path comes next.
::
