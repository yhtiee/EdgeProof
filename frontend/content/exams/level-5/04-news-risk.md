::question{id="nr-1" lesson="l5-what-happens-around-big-news"}
Around a big news release, spreads usually:
- [x] Widen, as liquidity providers pull back
- [ ] Shrink to zero
- [ ] Stay exactly the same
? Before and just after news, fewer quotes are offered, so spreads widen.
::
::question{id="nr-2" lesson="l5-what-happens-around-big-news"}
Why can stop-losses fill far from their level during news?
- [x] Price can jump past them with no trades in between
- [ ] Stops are switched off during news
- [ ] Brokers delay all orders by an hour
? Fast, thin markets cause slippage on stops.
::
::question{id="nr-3" lesson="l5-what-happens-around-big-news"}
The first move after a release:
- [x] Often reverses as traders digest the details
- [ ] Always continues for the rest of the day
- [ ] Is always upward
? Early moves are noisy and frequently snap back.
::
::question{id="nr-4" lesson="l5-what-happens-around-big-news"}
Which approach to news is safest for a beginner?
- [ ] Opening a large trade a few seconds before the release
- [x] Staying flat around high-impact releases
- [ ] Removing stops so news spikes can't hit them
? Avoiding the event removes the gap and slippage risk.
::
::question{id="nr-5" lesson="l5-no-trade-windows"}
A no-trade window is:
- [x] A rule that blocks new trades for a set time around high-impact events
- [ ] A time when the broker is closed
- [ ] A chart pattern
? It turns "be careful around news" into a precise, testable rule.
::
::question{id="nr-6" lesson="l5-no-trade-windows"}
Which no-trade rule is precise enough to test?
- [x] "No new trades from 30 minutes before to 30 minutes after high-impact events for either currency in the pair"
- [ ] "Be careful around news"
- [ ] "Avoid trading when it feels risky"
? A precise window can be applied the same way every time and tested.
::
::question{id="nr-7" lesson="l5-no-trade-windows"}
You trade EUR/USD. Which events should your no-trade rule cover?
- [x] High-impact events for both the euro and the US dollar
- [ ] Only US events
- [ ] Only events for the yen
? Either currency in the pair can be moved by its own news.
::
::question{id="nr-8" lesson="l5-no-trade-windows"}
You already have a trade open before a big release. Which choice reduces risk?
- [x] Close it, reduce size, or accept the gap risk knowingly before the event
- [ ] Add to it so the news move pays more
- [ ] Move your stop further away
? Decide deliberately before the release, not during it.
::
