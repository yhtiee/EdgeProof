::question{id="ec-1" lesson="l5-the-economic-calendar"}
An economic calendar shows:
- [x] When important data and events are due for each currency, with forecasts and results
- [ ] Bank holidays only
- [ ] Your broker's trading hours
? It lists releases such as jobs, inflation and rate decisions.
::
::question{id="ec-2" lesson="l5-the-economic-calendar"}
On a calendar, the "forecast" (or consensus) is:
- [x] What economists expect the number to be
- [ ] The final official result
- [ ] The previous month's number
? It's the expectation the actual result is compared against.
::
::question{id="ec-3" lesson="l5-the-economic-calendar"}
Which release usually counts as high-impact for the US dollar?
- [x] The monthly jobs report (non-farm payrolls)
- [ ] A small regional business survey
- [ ] A holiday announcement
? Jobs, inflation and Fed decisions are among the biggest US events.
::
::question{id="ec-4" lesson="l5-the-economic-calendar"}
Why check the calendar before every session?
- [x] To know when big moves and wide spreads are likely, and plan around them
- [ ] To find guaranteed trades
- [ ] Because the broker requires it
? Planning around events avoids being caught in surprise volatility.
::
::question{id="ec-5" lesson="l5-actual-versus-expected"}
Inflation comes in at 3.0%, exactly as forecast. The currency will most likely:
- [x] Move little, because nothing was surprising
- [ ] Jump sharply, because inflation is high
- [ ] Crash, because inflation is bad
? An expected number brings little new information.
::
::question{id="ec-6" lesson="l5-actual-versus-expected"}
What tends to move prices most when data is released?
- [x] The surprise: the gap between the actual number and the forecast
- [ ] Whether the number is above zero
- [ ] The previous month's number
? Markets react to how far reality differs from expectations.
::
::question{id="ec-7" lesson="l5-actual-versus-expected"}
US jobs growth beats the forecast, but last month's number is revised down sharply. What might happen?
- [x] Price can swing both ways as traders weigh the mixed news
- [ ] The dollar must rise
- [ ] Nothing, revisions are ignored
? Revisions and details can outweigh the headline.
::
::question{id="ec-8" lesson="l5-actual-versus-expected"}
UK inflation is forecast at 2.5% and comes in at 3.2%. Which way does this surprise point for the pound?
- [x] Up, because higher-than-expected inflation can raise expectations of rate rises
- [ ] Down, because inflation is always bad for a currency
- [ ] No direction at all
? A hot inflation surprise often lifts rate expectations, which supports the currency, though reactions can vary.
::
